Usage rules

  • Gold is accent, not decoration. Use for primary CTAs on auth, focus rings, links, key figures, verified badges and empty-state illustrations. Never more than one gold primary action per view.
  • Charcoal is the action color in-app. Send/Pay/Confirm buttons are charcoal 800; gold is reserved for trust moments and highlights.
  • Warm off-white canvas (#f6f6f4) softens the experience; pure white surfaces sit above it for elevation.
  • Money in, money out. Incoming = success green with + sign; outgoing = charcoal with − sign. Never color-only; always sign + status text.
  • Minimum contrast: body text on white ≥ 4.5:1; charcoal 700 on canvas passes AAA.

05 · Principles

Trust is the product.

A wallet is judged by how safe it feels. These are non-negotiable for every screen shipped under this system.

Clarity over cleverness

Plain language, one primary action, visible status. Never hide fees or state.

Identity first

Show name + username + photo/initial before money moves. Confirm screen for every payment.

Immutable references

Every transaction has a copyable reference. Audit trail, report flow, no silent rewrites.

Accessible by default

WCAG AA contrast, keyboard nav, focus rings, status as text + color, reduced-motion respect.

Honest simulation

Testnet/test labels always visible. Never pass simulated money as real.

Spatial generosity

Avoid dense grids for money. Let balances and lists breathe.
